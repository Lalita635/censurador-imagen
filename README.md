# Censurador de imágenes

Aplicación web para ocultar información sensible de imágenes.

Permite:

- Rectángulos
- Círculos / elipses
- Pixelado
- Desenfoque
- Color sólido
- Múltiples áreas
- Deshacer
- Limpiar áreas
- Descargar imagen resultante
- Drag & Drop
- Diseño responsive

## Privacidad

Las imágenes no se suben a ningún servidor.

Todo el procesamiento se realiza localmente en el navegador mediante Canvas.
